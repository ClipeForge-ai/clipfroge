# Clipforge (website version)

Paste a video link or upload a file, get vertical short clips.

Deploy on Render: New > Web Service > connect this repo > Runtime: Docker > Free plan.
Files are deleted after 1 hour. Max video length: 90 minutes (set MAX_SECONDS to change).

Only clip videos you own or have permission to use.
